# 빠른 시작 가이드

## 준비 사항

- Python 3.11 이상
- 가상 환경 활성화
- 필요한 패키지 설치

## 실행 방법

1. 프로젝트 루트에서 가상 환경을 활성화한다.
2. 필요한 패키지를 설치한다.
   - pip install -r requirements.txt
3. 서버를 실행한다.
   - c:/vibe_sdd/.venv/Scripts/python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
4. 브라우저에서 http://127.0.0.1:8000/ 에 접속한다.

## 검증 시나리오

- 새 할 일을 추가하고 목록에 나타나는지 확인한다.
- 완료 토글이 동작하는지 확인한다.
- 삭제 전 확인 절차가 동작하는지 확인한다.
- 필터를 변경해 목록이 올바르게 줄어드는지 확인한다.
- 페이지 새로고침 후에도 데이터가 유지되는지 확인한다.
